BoinaCoin es un ecosistema de economía virtual open source para Kick. Monedas, rangos, comandos, alertas en OBS y Discord — todo en tu servidor, todo bajo tu control.

Ver documentación → GitHub →

Funcionalidades

Todo lo que necesitas para gamificar tu stream de Kick de forma profesional.

Economía completa

Saldo, rangos, apuestas, duelos, cofres y hora feliz. Totalmente configurable y persistente.

Open Source total

Haz un fork, modifica el código C# y despliégalo. Sin cuotas mensuales ni depender de plataformas SaaS.

Tus propias frases

BoinaBot responde con un JSON de frases que tú escribes. Personalidad única para tu canal sin tocar código binario.

Integración nativa

Conexión directa entre Streamer.bot, Kick, Discord y OBS. Arquitectura modular diseñada para la estabilidad.

Cómo funciona

Una arquitectura diseñada para darte el control absoluto de tu contenido.

Streamer.bot actúa como el centro neurálgico que procesa los eventos de Kick en tiempo real, ejecuta la lógica económica y dispara acciones coordinadas en tu comunidad y tus directos.

¿Listo para desplegar?

Sigue estos 4 pasos para tener tu economía funcionando hoy mismo.

01

Descarga Streamer.bot

04

Personaliza
